# 햇살가계부

우리 집 위치의 지난 날씨와 시연용 전기 사용량을 겹쳐 태양광 설치 전후의
전기요금 변화를 비교하는 2026 AMI 기반 서비스 아이디어 공모용 동작형 웹
시제품입니다.

- 주소 검색은 사용자가 검색 버튼을 누를 때만 Nominatim 공개 API를 호출합니다.
- 위치 검색어와 검색 결과는 이 시제품이 별도로 저장하지 않습니다.
- 선택한 좌표의 지난 날씨는 Open-Meteo Archive API에서 조회합니다.
- 12개월 전기 사용량은 실제 고객 기록이 아니라 공식 AMI 표본을 참고한 시연용
  사용 시나리오입니다.
- 표시 금액은 주택용 저압 기본요금과 전력량요금만 비교한 예측입니다.
